# expand 架构

## 产品形态

expand 是常驻本地的紧凑文本扩展器，不启动监听端口，也不依赖服务端。

默认窗口为 520×620 的搜索面板；管理模式才扩展到 1040×720。点击 `—` 或按 `Esc` 会隐藏应用并保留全局快捷键；点击 `×` 或系统窗口关闭按钮会彻底退出进程。

Wails 单实例锁使用固定应用 ID `com.florune.expand`。第二次启动只向已有实例发送唤起请求，不创建第二个常驻进程。

窗口启用 Wails Frameless 模式，只保留 Vue 实现的标题栏。`.chrome` 是可拖动区域，`.chrome-actions` 明确标记为不可拖动，避免按钮点击被窗口拖拽吞掉。

## 全局快捷键流程

```text
用户选中 :trigger
    ↓ Ctrl + Alt + J
Windows RegisterHotKey
    ↓
临时发送 Ctrl+C 读取选区
    ↓
严格校验触发词
    ├── 已存在且可直接输出 → 恢复目标窗口并通过 SendInput 替换
    ├── 内置模板无需变量     → 直接替换
    └── 不存在/需要配置      → 打开紧凑窗口并预填触发词
```

替换不依赖 `Ctrl+V`、`Ctrl+Shift+V` 或应用自身的粘贴设置。应用先把选区折叠到右侧，再按触发词长度删除。
普通输入框使用 Windows `SendInput` 输入 Unicode 文本；Termius、Xshell、Windows Terminal 等终端使用目标窗口的键盘布局发送真实按键，
避免 Chromium/xterm 忽略 `VK_PACKET`。不会在内容末尾额外发送回车，内容本身的换行会被保留。
读取选区时临时使用剪贴板，但在文本注入前就恢复原内容，展开结果本身不会进入剪贴板。

`hotkey.Manager` 以 150ms 间隔记录最近的外部前台窗口，并按进程 ID 排除 expand 自己。快捷面板获得焦点后仍保留原目标：
单击快捷项只复制文本，双击快捷项才恢复该目标并填写；目标已经关闭或从未记录时，双击自动降级为复制。

## 数据层

### 本地用户索引

`internal/profile` 管理非敏感的 `profiles.json`。路径由程序生成的固定 ID 决定，前端不能传入任意文件路径。

### 用户加密库

每个本地用户对应一个 `profiles/<id>/vault.enc`。整个载荷统一加密，包含：

- 持久化快捷实例。
- 模板、自动发现的变量定义和用户变量值。
- 替换文本。
- 秘密值及快捷实例的秘密引用。

主密码通过 Argon2id 派生包装密钥；随机 256 位数据密钥由 AES-256-GCM 包装，载荷再由数据密钥使用 AES-256-GCM 加密。

### 内置模板

`data/**/*.yml` 仅作为不含个人数据的内置模板源文件，并在构建时嵌入可执行文件。应用启动后把当前版本同步到
`%AppData%\expand\library\_builtin`，独立运行 exe 不依赖仓库目录。该子目录由应用维护，会清理已经从发行版本删除的旧模板。
模板不会覆盖用户的加密实例；相同触发词存在时，用户实例优先。

模板文件按 `mysql`、`redis`、`kafka`、`docker`、`linux`、`nginx`、`git`、`common` 和 `ai` 分类。所有内置模板必须在不传变量时成功渲染；尚未配置的连接信息使用 `MYSQL_HOST`、`REDIS_HOST`、`KAFKA_TOPIC` 等显式占位符。该约束由集成测试覆盖。

用户快捷词不按 `type` 分叉表单。分类只用于浏览和筛选；模板中的 `{{VARIABLE}}` 是唯一的动态结构，
前后端都会自动发现变量并为未配置项保留可见占位符。内置模板可以直接复制或填写，也可以预填到编辑器后保存进当前用户的加密库。

## 会话边界

- 后端只维护一个当前解锁用户，不接受前端指定的“目标用户 ID”进行快捷词 CRUD。
- 用户切换前锁定旧加密库。
- 24 小时无操作后自动锁定；程序退出时立即擦除内存中的解密会话。
- 锁定时清空载荷对象中的秘密值和替换内容，并擦除数据密钥字节。

## 平台

Windows 使用 `RegisterHotKey`，只注册 `Ctrl + Alt + J`，不安装全键盘钩子。Linux 保留存储和界面能力，但全局选区替换尚未实现。

## 可观测性

`internal/applog` 将运行事件写入 `%LOCALAPPDATA%\expand\logs\expand.log`，单文件上限 2 MiB，并保留一个轮转备份。Vue 的全局异常、未处理 Promise 和挂载失败会通过 Wails 上报；成功挂载会写入 `frontend.ready`。日志上报会截断超长内容并对常见凭证格式进行脱敏。
